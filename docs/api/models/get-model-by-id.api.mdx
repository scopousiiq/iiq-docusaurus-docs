Retrieves a specific model record by its unique identifier.

**Prerequisites**
- **ModelId** - Use [POST /api/v1.0/models](/docs/api/models/search-models) to search for models, extract `Items[].ModelId`

**Workflow Example**
1. Search models: [POST /api/v1.0/models](/docs/api/models/search-models) → get `ModelId`
2. Call this endpoint: GET /api/v1.0/models/\{ModelId\}
3. View complete model details including manufacturer, category, and metadata

**Related Endpoints**
- [POST /api/v1.0/models](/docs/api/models/search-models) - Search for models
- [POST /api/v1.0/models/\{ModelId\}](/docs/api/models/update-model) - Update this model
- [DELETE /api/v1.0/models/\{ModelId\}](/docs/api/models/delete-model) - Delete this model
