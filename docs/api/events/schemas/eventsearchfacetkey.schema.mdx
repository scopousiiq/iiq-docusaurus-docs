Facet keys for event search. The supported facets are organized by category:

## Event Identity & Status
| Facet | Description | Value Type |
|-------|-------------|------------|
| `Event` | Specific event by ID | UUID |
| `EventStatus` | Event approval status | UUID |
| `EventType` | Event category/type | UUID |
| `EventsInSeries` | Events belonging to a series | Boolean |

## Scheduling & Dates
| Facet | Description | Value Type |
|-------|-------------|------------|
| `EventDate` | Event date range | DateExpression (`range:year`, `range:today`, `daterange:MM/dd/yyyy-MM/dd/yyyy`) |
| `EventDayOfWeek` | Day of week filter | DayOfWeek name (`Monday`, `Wednesday`, etc.) |
| `EventTimeOfDay` | Time of day range | TimeRange (`timerange:HH:mm-HH:mm`) |
| `DaysBeforeEvent` | Days until event starts | NumericExpression (`numoperator:lessthan:5`) |
| `DaysAfterEvent` | Days since event ended | NumericExpression |
| `Upcoming` | Future non-cancelled events | Parameterless |
| `CreatedDate` | Record creation date | DateExpression |

## Location & Rooms
| Facet | Description | Value Type |
|-------|-------------|------------|
| `EventLocation` | Event location/building | UUID |
| `EventRoom` | Specific room | UUID |
| `EventRoomType` | Room type/category | UUID |

## People & Organizations
| Facet | Description | Value Type |
|-------|-------------|------------|
| `EventOwner` | Event owner/requestor | UUID |
| `EventOrganization` | Associated organization | UUID |
| `EventOrganizationType` | Organization type | UUID |
| `EventOrganizationStatus` | Organization status | UUID |
| `ContactEmail` | Organization contact email | String |

## Insurance & Compliance
| Facet | Description | Value Type |
|-------|-------------|------------|
| `InsuranceExpired` | Organization insurance expired | Boolean (`yes`/`no`) |
| `OrgInsuranceExpirationDate` | Insurance expiration date | DateExpression |

## Financial
| Facet | Description | Value Type |
|-------|-------------|------------|
| `FeeType` | Fee type | UUID |
| `RateType` | Rate type | UUID |
| `NumberOfAttendees` | Expected attendee count | NumericExpression |

## Custom & Extended
| Facet | Description | Value Type |
|-------|-------------|------------|
| `EventField` | Event field values | String |
| `EventCustomField` | Custom field values (append subtype: `text`, `number`, `datetime`, `users`, `assets`, `locations`, `multiselect`, `phone`, `complex`) | Varies |

Call `/api/v1.0/filters/for/entitytype/{entityTypeId}` to retrieve the latest supported keys.
