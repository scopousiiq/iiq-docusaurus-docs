Request body for querying events via [POST /api/v1.0/events/query](/docs/api/events/get-events-by-query-post). This model extends `RequestOptionParameter` — filters, paging, and sorting are nested inside the `RequestOptions` wrapper, NOT at the request root.

**Correct structure**:
```json
{
  "RequestOptions": {
    "Paging": { "PageSize": 50, "PageIndex": 0, "SortField": "StartDatetime", "SortDirection": "Ascending" },
    "Filters": [{ "Facet": "EventDate", "Values": ["range:year"] }]
  },
  "Strategy": "Default"
}
```

**Common mistake**: Placing `Filters` or `Paging` at the root level will be silently ignored — always nest them inside `RequestOptions`.

See `EventSearchFilter` for the complete list of supported event facets with value formats and examples. See `RequestOptions` for paging and sorting documentation.
