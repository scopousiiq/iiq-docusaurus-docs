Creates multiple purchase order records in a single request for efficient batch creation of procurement records. Each purchase order in the array is created independently.

**Prerequisites**
1. **SupplierId** (optional per PO) - Use [GET /api/v1.0/parts/suppliers](/docs/api/parts/list-part-suppliers) to list suppliers, extract `Items[].PartSupplierId`.
2. **FundingSourceId** (optional per PO) - Use funding sources API to get available funding sources.

**Workflow Example**
1. (Optional) Prepare supplier references: [GET /api/v1.0/parts/suppliers](/docs/api/parts/list-part-suppliers).
2. Create multiple POs: [POST /api/v1.0/purchase-orders/ids](/docs/api/parts/create-purchase-orders-bulk) with array of PO data.
3. Extract created PurchaseOrderIds from response for verification.
4. Verify creation: [GET /api/v1.0/purchase-orders/ids](/docs/api/parts/get-purchase-orders-by-ids) with the returned IDs.

**Minimal Required Fields**: Each purchase order must include PoNumber.
